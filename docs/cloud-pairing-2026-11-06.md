# 云同步一致性与手机配对修改说明（2026-11-06）

## 本批范围

阶段 5：当前表与待更新数据隔离、不可变缓存、保持工作表选择、扫码配对及发现协议调整。

## 云同步

- 后台检查沿用当前工作表名称，并显式检查远端版本，不再因选择了表名而跳过远端检查。
- 待更新结果独立保留，用户确认或允许自动应用后才更新当前表名、内容及缓存元数据。
- 按文件内容哈希保存独立快照，后台下载不再覆盖已确认版本。旧缓存首次检查前迁移为快照。
- 当前表名、版本、路径和表名列表写入一个设置值，避免多字段保存一半；启动和离线恢复均读取同一份元数据。
- 与已应用版本比较识别更新，不再仅依赖本次是否下载，因此待确认更新不会因下一次检查未下载而丢失。
- 手动与后台同步共用并发门禁。当前本地文件单独标识，后台更新不覆盖本地数据。
- 统一出货历史恢复使用的记录键格式，修复记录 ID 调整后旧拼接格式未同步的问题。

## 手机配对

- UDP 发现仅返回电脑名称、端口、无查询凭证的地址；mDNS TXT 仅包含名称。
- 首次连接需扫描电脑面板二维码；iOS 发现结果不再授予访问权限。
- 已配对后，仅对相同协议、主机和端口使用手机本地保存的链接重连，避免向不同服务发送凭证。
- 口令改为系统随机源生成的 256 位随机值；旧短口令自动迁移，旧链接需重新扫码。
- 更新口令后旧 Cookie 被拒绝。启动日志不再打印包含口令的 URL。
- 本批使用共享扫码访问凭证；未增加逐设备授权列表或 TLS。
