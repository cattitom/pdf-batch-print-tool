# 手机协作与直接落库修改说明（2026-11-06）

## 本批范围

阶段 4：手机勾选直接持久化、记录标识、数据集隔离和并发版本校验。沿用既有数据库和历史记录规则。

## 修改内容

- 桌面与手机共用数据库实例，统一事务提交；固定手机状态锁、数据库锁的顺序。
- 校验记录、数据集和版本，保存数据库后才更新内存、递增版本并返回成功。
- 记录 ID 使用规范化单号、入库号、商品名的 JSON 元组，与行号无关；编辑身份字段会形成新记录。
- 应用新表生成来源标识，来源或表结构变化时生成新数据集，拒绝旧请求。
- 旧版本返回 HTTP 409；批量请求先校验全部记录，避免部分成功。
- 桌面轮询只读取状态，不再将手机状态写回；冲突时显示最新快照，用户核对后显式重试。
- 手机网页发送版本信息；iOS 离线队列保留原始版本，冲突时停止自动重试、提示核对并提供放弃入口。
- 服务运行时拒绝缺少版本的旧客户端请求。更新后请刷新手机网页；旧离线缓存需核对后重新操作。
