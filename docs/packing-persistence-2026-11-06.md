# 出货记录保存修改说明（2026-11-06）

## 本批范围

阶段 3：桌面勾选、批量标记与手机轮询写库的可靠性。沿用数据库结构和记录指纹，保留已有数据。

## 修改内容

- 新增批量保存命令，单行、多行共用事务入口。
- 去除标识字段首尾空白，拒绝将同时缺少单号与入库号的行标为已出。
- 整批事务提交，任意一行失败则全部回滚。
- 数据库保存成功后再更新界面、勾选缓存和手机服务内存。
- 失败保留原状态、显示原因，提供整批重试和放弃入口。
- 保存期间防止重复提交，待处理失败阻止后续勾选，避免重试覆盖。
- 批量标记成功后才清除所选行。
- 手机轮询按当前行数据整批保存，移除旧闭包索引写库路径。
